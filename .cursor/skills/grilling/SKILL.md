# Grilling (primitive)

## Algorithm

1. Identify the decision tree (options + unknowns).
2. Ask the highest-leverage unresolved question.
3. Update the tree from the answer.
4. Repeat until no material unknowns remain (or user accepts assumptions).
5. Summarize locked decisions before exiting.

## Question quality

- Forces a choice (A/B/C) or a concrete constraint
- Surfaces hidden stakeholders, failure modes, non-goals
- Avoids “nice to have?” laundry lists

## Output

Always leave a written trail in the active research/spec/wayfinder artifact — never only in chat.
