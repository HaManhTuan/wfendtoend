# /greenfield

Bootstrap a **new product** with cursor-workflow (full discover).

1. Run **`setup-project`** if `AGENTS.md` is missing in this repo.
2. Deep **`discover`**: users, MVP, non-goals, stack constraints, glossary seed.
3. **`lock-scope`** for MVP only.
4. **`write-plan`** + **`to-tickets`** (tracer-bullet vertical slices).
5. Optional: **`parallel-worktrees`** for independent foundation tickets.
6. **`implement`** → **`dual-review`** → **`verify`** → **`ship`** as requested.
7. End with **`retro`** after the first milestone.
